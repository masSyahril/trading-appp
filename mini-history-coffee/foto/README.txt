lalu daftarkan namanya di CONFIG.photos pada app.js, contoh:

  photos: [
    { src: 'foto/kedai-malam.jpg', caption: 'Teras kedai malam hari' },
    { src: 'foto/kopi-susu.jpg', caption: 'Kopi susu aren' },
  ],

Foto ini dipakai di bagian atas halaman dan galeri "Suasana kedai"
selama feed Instagram belum tersambung.
